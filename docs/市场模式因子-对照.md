# 市场模式因子分支对照（Quantlab_regime vs Quantlab）

2026-10-09 建。本分支 = 原分支的副本 + 5 列市场模式因子 + 按新分布重标定的分位线。
原分支 `G:\个人量化\Quantlab` 一字未改（本目录下所有复算脚本对它只读）。

一句话结论：完整性与无前视校验全部通过；但同一回测窗口（2023-01-05 → 2026-09-24，45 个月度
评估，费后，100 万本金）上，本分支用生产线或重标定线整体低于原分支基线，6 颗种子配对差
5/6 与 6/6 为负。模型层面：截面 RankIC 名义略高（去标签重叠后不显著），新增的是"整池分数
每天整体上下动"这个通道——它不是有效择时、还会把候选数搅散。回测差异主要来自执行层
（平均持仓：基线 3.7~4.1 只、本分支生产线 3.0~3.4 只、重标定线 1.5~1.9 只）与路径，不是选股信号的退化。

## 5. 模型层面（`logs/regime_vs_base_ic.log` + `logs/regime_pipeline_train.log`）

- 逐日 RankIC：基线 中位 +0.0192 / 均值 +0.0168 → regime 中位 +0.0269 / 均值 +0.0286；
  配对差中位 +0.0108（53.8% 的交易日更好）。全日 t 检验 p = 0.023，但标签重叠 5 天，
  每 5 个交易日抽 1 天后 p = 0.127 —— 不算显著改善。
- 分数分布拆分：全样本 σ 0.00853 → 0.02005；其中"日间"成分（日中位序列的 std）
  0.00266 → 0.01802（×6.8），"日内"截面 std 0.00772 → 0.00734（基本不变）。
  即新增的几乎全是"整池分数每天整体上下动"的量。
- 该日间摆动不是有效择时：「全池分数中位 vs 当日全池平均前向收益」时序相关
  基线 +0.1388 → regime +0.0110（按月 +0.3993 → +0.0428）。
- 特征重要性 Top-5 全部是 mkt 列（mkt_vol_20d 2935.8 / mkt_ret_20d 2153.1 /
  mkt_dd_60d 1961.4 / mkt_breadth_20d 1528.3 / mkt_snr_20d 1046.3），第 6 名起才是原因子
  （volatility_60d 176.9）——模型把绝大部分重要性放在了市场状态上。

## 6. 怎么读 / 保留

1. 本窗口上两种线档都低于基线、方向一致（配对 5/6、6/6 为负），但幅度要对照本项目的重训
   噪声读：同一流程只换种子，期末值跨度就有 ~29pp（基线区间 [+21.14, +50.41]）。所以
   中位 −15.7pp / −27.6pp 不能直接等于"结构恶化"，只能说"在本窗口没有证据支持更好"。
2. 不依赖种子的结构性事实有三条：①新分数分布的日间摆动是基线的 6.8 倍；②新 P94 买线
   之下 76.2% 的交易日凑不满 12 只名额；③模型重要性被 mkt 列主导。这是"市场模式因子以
   这种方式加入"的直接后果，换种子不会消失。
3. 没做的事：5 列 mkt 因子没有单因子 IC（同一天全池同值，截面 IC 无定义）；没有扫
   "只加部分列 / 换计算窗口 / 对 mkt 列先做截面外归一化"等变体；没有重取历史数据版本对照。
